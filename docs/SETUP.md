# إعداد وتشغيل Flight Hunter AI

## المتطلبات
- Python 3.11 أو أحدث.
- اتصال بالإنترنت لتثبيت الحزم.

## التثبيت على Windows
```powershell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
streamlit run app.py
```

افتح العنوان المحلي الذي يطبعه Streamlit في الطرفية.

## الاختبارات
```powershell
pytest -q
```

## مفاتيح مزودي البيانات
ضع بيانات الاعتماد في ملف `.env` المحلي فقط. لا ترسلها في المحادثات ولا ترفعها إلى Git.
لن يعمل البحث الحي قبل تنفيذ موصل المزود في مرحلة التكامل.

## ملاحظات النطاق
- الإصدار الأول مخصص للبحث عن الرحلات من وإلى المطارات المصرية.
- التطبيق يعرض روابط الانتقال إلى مواقع الحجز الخارجية.
- لا يوجد دفع أو إصدار تذاكر داخل التطبيق.
- يجب توضيح وقت تحديث السعر وشروط الأمتعة والعملة عند دمج كل مزود.
