# Flight Hunter AI

محرك بحث ومقارنة رحلات بواجهة عربية، يركز على مصر والسعودية ويجمع للمستخدم روابط البحث في شركات الطيران ومواقع المقارنة.

## مبادئ المشروع
- لا يتطلب إنشاء حسابات مطورين أو مفاتيح API أو بيانات اعتماد.
- لا ينفذ حجزاً أو دفعاً أو إصدار تذاكر داخل التطبيق.
- يعرض روابط مباشرة للمواقع الأصلية للبحث اليدوي، مع جدول مقارنة لعروض الأسعار التي تم إدخالها من ملفات CSV أو مصادر عامة مصرح بها.
- لا يدّعي جلب أسعار حية من المواقع ما لم تتوفر وسيلة عامة ومصرح بها للتحقق منها. لا يجمع أسعار Wego أو Wingie آلياً.
- لا يعرض أسعاراً وهمية أو تقديرية على أنها أسعار فعلية.

## المصادر المدرجة
- شركات مصرية: مصر للطيران، إير كايرو، النيل للطيران، فلاي إيجيبت.
- شركات سعودية: الخطوط السعودية، طيران ناس، طيران أديل، طيران الرياض.
- المقارنة: Wego مصر والسعودية، Wingie مصر والسعودية، المسافر مصر والسعودية، الرحلة، Google Flights. Wego وWingie متاحان للبحث اليدوي فقط في هذه النسخة.
- المطارات: مطارات مصر والسعودية، مع وجهات دولية شائعة.

## مقارنة الأسعار

توجد صفحة مقارنة لعروض الأسعار الفعلية المحمّلة عبر ملف CSV. تدعم توحيد درجات السفر (اقتصادي، اقتصادي ممتاز، أعمال، أولى)، العملة، الرحلات المباشرة، وترتيب النتائج من الأرخص إلى الأغلى. تحفظ كل نتيجة اسم المصدر ووقت التحقق، ولا تعرض أسعاراً افتراضية.

أعمدة CSV المطلوبة:
`provider,airline,origin,destination,departure_at,arrival_at,cabin_class,price,currency,stops,duration_minutes,checked_at`

يمكن إضافة `baggage_summary` و`booking_url` اختيارياً. روابط العروض يجب أن تستخدم HTTPS.

**قيد مهم:** السماح للمستخدم بالتصفح دون تسجيل دخول لا يمنح التطبيق إذناً لجمع بيانات الموقع آلياً. شروط Wego تمنع إرسال استعلامات آلية، وشروط Wingie تمنع الاستخلاص الآلي للبيانات وجمع الأسعار. لذلك لا توجد موصلات كشط لهذه المواقع؛ تظهر روابطهما للبحث اليدوي فقط. لن يتم تفعيل موصل تلقائي إلا بعد وجود إذن أو وسيلة عامة تسمح بذلك صراحةً.

## طريقة البحث الحالية
يدخل المستخدم خط الرحلة والتواريخ وعدد المسافرين، ثم ينشئ التطبيق رابط بحث مهيأ في Google Flights ويعرض روابط المواقع الرسمية ومواقع المقارنة. ويمكنه تحميل ملف CSV بعروض أسعار فعلية لتصفية الأسعار حسب الدرجة والعملة والتوقفات. الروابط إلى مواقع شركات الطيران تفتح مواقعها الأصلية؛ لا نزعم أنها روابط نتائج بحث مهيأة ما لم يكن تنسيقها موثقاً.

**تنبيه:** هذه النسخة لا تسحب الأسعار آلياً من كل موقع. كثير من المواقع لا توفر وصولاً عاماً موثوقاً للأسعار دون API أو شراكة. لذلك تظهر روابط البحث الخارجية بدلاً من أسعار غير متحققة. يمكن إضافة موصلات عامة فقط عندما تسمح شروط المصدر بذلك ودون حسابات أو مفاتيح.
