# Flight Hunter AI

وكيل ذكي لمقارنة أسعار تذاكر الطيران، يبدأ بالسوق المصري، ويعرض أفضل الخيارات مع روابط الانتقال إلى مزود الحجز لإتمام العملية خارجيًا.

## نطاق الإصدار الأول
- واجهة عربية باستخدام Streamlit.
- بحث رحلات ذهاب فقط أو ذهاب وعودة.
- توحيد عروض مزودي البيانات وترتيبها حسب السعر والمدة والتوقفات.
- روابط انتقال إلى موقع مزود الحجز؛ لا يوجد تنفيذ دفع أو إصدار تذاكر داخل التطبيق.
- لا تُعرض أي أسعار تجريبية على أنها أسعار حقيقية.

## الحالة الحالية
- المرحلة الأولى: تأسيس هيكل المشروع والإعدادات الأساسية.
- المرحلة الثانية: واجهة بحث عربية RTL واختيار المطارات والتواريخ والمسافرين.
- المرحلة الثالثة: موصل Amadeus OAuth 2.0 وFlight Offers Search، مع توحيد العروض وترتيبها وعرض الأسعار التي يعيدها المزود فقط.

لتفعيل البحث المباشر، أضف مفاتيح Amadeus إلى ملف `.env` المحلي وفق `docs/AMADEUS.md`. يبدأ الإعداد ببيئة الاختبار؛ لا تُعرض عروض مباشرة قبل توفير المفاتيح.

## التشغيل المحلي
راجع `docs/SETUP.md`.

## الأمان
انسخ `.env.example` إلى `.env` وأضف مفاتيح API محليًا. لا ترفع ملف `.env` إلى Git.
